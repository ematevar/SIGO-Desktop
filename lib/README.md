# Librerías externas (`lib/`)

Coloca aquí los JARs requeridos por el proyecto:

- `mysql-connector-j.jar` — Conector JDBC para MySQL 8.
- `jcalendar-1.4.jar` — Selector de fechas `JDateChooser` para Swing.
- `junit-4.13.2.jar` y `hamcrest-core-1.3.jar` — Ejecución de pruebas unitarias con `ant test`.
